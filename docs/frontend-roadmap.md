# План разработки фронтенда

Согласован с пользователем 14 ноября 2026 года. Точка входа для работы над
фронтендом в любом чате: порядок этапов, границы и состояние. Публичные интерфейсы
не дублируются, а берутся из документов ниже.

## Документы и приоритет

1. [AGENTS.md](../AGENTS.md) — правила работы с репозиторием и Git.
2. [API-контракт](api.md) и [примеры ответов](api-examples/) — единственный
   источник форм данных. Расхождение с бэкендом правится в контракте отдельным
   коммитом.
3. [Макет главного экрана](../design/main-screen.html) — раскладка и дизайн-токены.
4. [PRODUCT.md](../PRODUCT.md) — продукт, пользователи, принципы.

## Исходные условия

- Бэкенд на этапе 0: работает только `GET /api/health`. Фронтенд живёт на моках из
  `docs/api-examples/` и переключается на настоящий API без правки компонентов.
- Раскладка выбрана: навигация | чат | панель «Отчёт / Браузер». Только десктоп,
  минимальная ширина 1024 px. Мобильная версия отложена.
- Деньги фронтенд не считает, а только форматирует строки. Идентификаторы не
  разбирает, неизвестные поля игнорирует, тексты показывает как пришли.
- Интерфейс на русском. Никаких профилей и аккаунтов.

## Решения по стеку

- Vite, React, TypeScript, каталог `frontend/`.
- Стили: CSS-переменные из макета и CSS Modules, без UI-библиотек.
- Данные: TanStack Query для REST; сообщения чата из SSE хранятся отдельно и
  вставляются или заменяются по `id`.
- Моки: MSW, ответы берутся из `docs/api-examples/`; для SSE — эмулятор событий.
- Проверки: Vitest и Testing Library, `tsc`, oxlint (линтер из шаблона Vite).
- Палитра: акцент тёмный оранжевый `#D64200`, выбран пользователем 14 ноября 2026,
  нейтральные тона тёплые. Всё задаётся токенами в `src/styles/tokens.css`; макет
  `design/main-screen.html` остаётся в «Графите» и показывает только раскладку.
