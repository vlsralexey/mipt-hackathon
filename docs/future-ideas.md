# Идеи на будущее

Здесь собираем идеи для дальнейшего развития продукта. Они не входят в текущий
план работ, пока не будут отдельно согласованы.

## Локальная проверка документов на персональные данные

Добавить возможность подключить локальную модель для первоначальной проверки
загруженного документа на наличие персональных данных до его отправки во внешние
сервисы.

Если модель найдёт возможные персональные данные, уведомить пользователя,
показать найденные фрагменты и предложить очистить документ: удалить или
обезличить эти данные. Пользователь сможет проверить предложенные изменения
перед продолжением обработки.

Проверка и очистка должны выполняться локально. Исходный документ сохраняется
без изменений; дальнейшая обработка использует очищенную копию после
подтверждения пользователя.
