# Выкладка на сервер

Простая выкладка по IP, без домена, HTTPS и авторизации. Подходит для
временного демо. Сервис будет открыт всем, кто знает адрес, поэтому поставьте
лимит расходов на ключ в OpenRouter.

## 1. Создать сервер

В панели TimeWeb или HostVDS:

- ОС: **Ubuntu 24.04**;
- локация: **Россия** (Москва или Петербург), иначе ЕИС может не открываться;
- **2 vCPU, 4 ГБ RAM, 30-40 ГБ диска**;
- публичный IPv4;
- вход по SSH-ключу или паролю.

Дальше `IP` означает адрес сервера из панели.

## 2. Скопировать код

На своём компьютере, из корня репозитория:

```bash
git archive deploy | ssh root@IP "mkdir -p /opt/nmck && tar -x -C /opt/nmck"
```

Копируется последний коммит ветки `deploy`, без `.env` и локальных данных.

## 3. Установить Docker

```bash
ssh root@IP
curl -fsSL https://get.docker.com | sh
```

## 4. Проверить доступ к ЕИС и OpenRouter

```bash
curl -sI https://zakupki.gov.ru | head -1
curl -sI https://openrouter.ai | head -1
```

Оба должны ответить строкой с `HTTP/... 200` или `301/302`. Если ЕИС не
отвечает, пересоздайте сервер в другой российской локации.

## 5. Настроить и запустить

```bash
cd /opt/nmck
cat > .env <<'EOF'
OPENROUTER_API_KEY=ваш_ключ
OPENROUTER_MODEL=deepseek/deepseek-v4.1-flash
BACKEND_HOST=0.0.0.0
BACKEND_PORT=80
EOF
docker compose up --build -d --wait
```

Первая сборка идёт 5-10 минут (Chromium и фронтенд). Затем откройте в браузере
`http://IP`.

Если страница не открывается, проверьте, что в панели провайдера не закрыт
порт 80 (раздел «Firewall» или «Сетевые правила»).

## Обновить

На своём компьютере снова выполните шаг 2, затем на сервере:

```bash
cd /opt/nmck && docker compose up --build -d --wait
```

Данные (закупки, настройки) хранятся в томе `nmck-data` и при обновлении
сохраняются.

## Полезное

```bash
docker compose logs -f backend   # логи
docker compose restart backend   # перезапуск
docker compose down              # остановить
```

Когда демо закончится, удалите сервер в панели провайдера, чтобы не платить.
